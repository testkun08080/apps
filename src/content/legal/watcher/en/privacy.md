## 1. Introduction

Watcher (the "App") respects your privacy. This policy explains what information the App handles.

## 2. Information We Collect

The App handles the following information to provide sign-in and sync features.

| Data | Purpose | Storage |
|------|---------|---------|
| Authentication info (user ID, email address, etc.) | Sign-in, identity verification | Clerk (authentication provider) |
| Watch themes, reports, and settings data | App functionality, sync across devices | On-device SQLite / API server (Cloudflare Workers, D1) |
| Device identifier, push token | Identifying where to deliver notifications | API server (Cloudflare Workers, D1) |
| Purchase status (subscription) | Providing Pro features, verifying purchase status | RevenueCat / Apple App Store |

## 3. Third-Party Services

| Service | Purpose | Provider |
|---------|---------|----------|
| Clerk | Authentication (sign-in) | Clerk, Inc. |
| Cloudflare Workers / D1 | API and data sync infrastructure | Cloudflare, Inc. |
| RevenueCat / Apple App Store | Processing in-app purchases, verifying purchase status | RevenueCat, Inc. / Apple Inc. |
| Expo Push Service | Push notification delivery | Expo / Expo Platform Inc. |

Information handled by each service is governed by that service's own privacy policy.

- Clerk: https://clerk.com/legal/privacy
- Cloudflare: https://www.cloudflare.com/privacypolicy/
- RevenueCat: https://www.revenuecat.com/privacy
- Apple: https://www.apple.com/legal/privacy/
- Expo: https://expo.dev/privacy

## 4. Device Permissions

The App may request the following permissions.

- Notifications: to receive report notifications
- Apple account information: for authentication when signing in with Apple
- Google account information: for authentication when signing in with Google

## 5. Tracking

The App does not use tracking for cross-app or cross-site advertising purposes.

## 6. Data Deletion

Deleting the App from your device removes the data stored on that device. For questions about account-related data stored on our servers, please contact support.

## 7. Contact

For questions about this policy, please contact us at the email address at the bottom of this page.
